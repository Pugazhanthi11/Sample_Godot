# 🦷 Sample 3D Teeth Model Viewer

A simple real-time 3D dental visualization project developed using **Godot Engine 4.7.1** and **Blender**. This project demonstrates importing a custom 3D tooth model into Godot and providing interactive camera controls for viewing the model from different angles.

> This project was created as a learning prototype for the **HapticVerse** dental simulation project.

## 🌐 Live Demo

## ✨ Features

- 🦷 Custom 3D Tooth Model
- 🎮 Interactive Mouse Rotation
- 🔍 Mouse Wheel Zoom
- 💡 Real-Time Lighting
- 🌎 3D Environment Setup
- ⚡ Built with Godot Engine 4.7.1
- 🎨 Tooth Model Created in Blender

| Action | Control |
|---------|----------|
| Rotate Tooth | Left Mouse Button + Drag |
| Zoom In | Mouse Wheel Up |
| Zoom Out | Mouse Wheel Down |

## 🎯 Project Objective

The goal of this project is to understand the complete workflow of creating a 3D interactive application using Godot.

This prototype focuses on:

- Importing Blender models into Godot
- Scene setup
- Camera controls
- Real-time lighting
- Interactive 3D visualization

This serves as the foundation for the upcoming **HapticVerse** dental simulation project.
